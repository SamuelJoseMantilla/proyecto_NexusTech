# 🚀 Nexus Tech: La Transformación Digital

Plataforma web moderna, rápida y adaptable diseñada para relanzar la histórica revista impresa de tecnología "Nexus Tech" al entorno digital, asegurando su permanencia y atrayendo a una nueva generación de lectores.

---

## 📁 Estructura del Proyecto

El código fuente está organizado siguiendo una arquitectura modular basada en estilos CSS y metodologías limpias:

Proyecto_Skill_HTML_CSS_NexusTech/
├── assets/
│   ├── css/
│   │   ├── main.css       # Importaciones, tipografía y variables globales (:root)
│   │   ├── layout.css     # CSS Grid, Flexbox y contenedores base
│   │   ├── components.css # Tarjetas, botones, inputs y componentes reutilizables
│   │   └── responsive.css # Media queries específicas para adaptabilidad móvil
│   ├── img/               # Imágenes optimizadas del sitio
│   └── icons/             # Recursos gráficos secundarios
├── pages/
│   ├── categorias.html    # Filtro dinámico con 15 artículos y paginación
│   ├── resenas.html       # Análisis de gadgets con ratings y tabla comparativa
│   ├── comunidad.html     # Foro de debate con FAQ en acordeón y tendencias
│   ├── eventos.html       # Calendario de eventos clave y cumbres destacadas
│   └── contacto.html      # Formulario con validación pura CSS y mapa estático
├── index.html             # Landing page principal con banner y destacados
└── README.md              # Documentación técnica del proyecto

## 🛠️ Tecnologías y Metodologías Utilizadas

* **HTML5 Semántico:** Estructura de etiquetas optimizada para accesibilidad y SEO (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
* **CSS3 Moderno:**
  * Uso obligatorio de **Variables CSS (`:root`)** para la gestión centralizada de la paleta de colores y tipografías.
  * **CSS Grid y Flexbox** para el diseño de cuadrículas responsivas (como la sección de 15 artículos en columnas).
  * **Metodología BEM (Bloque, Elemento, Modificador)** para mantener un código ordenado, escalable y mantenible.
  * **Validación pura con CSS** utilizando pseudoclases (`:valid` e `:invalid`) sin requerir lógica de JavaScript.
* **Diseño Responsivo (Mobile First):** Adaptación fluida a través de *Media Queries* personalizadas para dispositivos móviles, tablets y escritorios.

## 🖥️ Instrucciones para Visualizar el Proyecto

1. **Clonar o descargar** el repositorio en tu equipo local.
2. Asegúrate de mantener la **estructura de carpetas** intacta para que las rutas relativas de los archivos CSS e imágenes funcionen correctamente.
3. Abre el archivo principal **`index.html`** directamente en tu navegador web preferido, o utiliza una extensión de desarrollo (como *Live Server* en Visual Studio Code) para una experiencia de visualización en tiempo real.
4. Navega de forma intuitiva entre el menú superior para explorar todas las secciones: *Inicio, Categorías, Reseñas, Comunidad, Eventos y Contacto*.
